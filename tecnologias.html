Sección 1 · Arquitectura del sistema

3 bloques principales

Los archivos Excel entran por una sola puerta y salen en tres paneles distintos según el rol del usuario.

Bloque Qué hace
Carga y Validación Único punto de entrada gestionado por RRHH. Valida columnas obligatorias y evita registros duplicados.
Motor de Reglas (Servidor) Construido como una API REST. Aplica el corte del 21 al 20, gestiona turnos y procesa únicamente las solicitudes aprobadas, sin recalcular nada en el navegador.
Sitio Web (Cliente) Consume la información por HTTPS y distribuye las vistas en tres grandes módulos: Dashboard diario (RRHH), Resumen de nómina (Contabilidad) e Indicadores (DO).

Sección 2 · Tecnología definida

11 herramientas, un solo stack

El stack prioriza herramientas gratuitas, modernas y fáciles de mantener, separando completamente la capa de ingesta de datos del frontend.

Capa Tecnología Qué hace
Frontend React 18+ Vite + TypeScript Aplicación web de una sola página (SPA) con las pantallas del sitio.
Estilos Tailwind CSS con tokens de marca Paleta, tipografía y logo reemplazables sin tocar los componentes (RNF-003).
Gráficos Recharts Visualización de los indicadores de asistencia, headcount y rotación.
Backend Python 3.12 + FastAPI Construcción de la API REST y el motor de reglas de negocio (corte 21-20, turnos).
Procesamiento de Excel pandas + openpyxl Lectura de los reportes crudos de Z-BioTime y exportación a formatos .xlsx.
Exportación a PDF ReportLab Generación del resumen de nómina y el panel de indicadores en PDF.
Base de datos PostgreSQL 16 (SQLite en desarrollo local) Almacenamiento relacional de empleados, horarios, marcaciones, solicitudes, cargas y usuarios.
Acceso a datos SQLAlchemy + Alembic Manejo de modelos de base de datos y migraciones versionadas de forma programática.
Autenticación JWT en cookie HttpOnly + hash Argon2 Gestión de sesiones por rol y cifrado de contraseñas de alta seguridad (RNF-002).
Pruebas (Testing) pytest, Postman y Playwright Pruebas automatizadas de las reglas de negocio, la API y recorridos de pantallas en navegadores web.
Despliegue y Hosting Docker Compose + Nginx con HTTPS (Let's Encrypt) Contenerización del entorno para un servidor único, accesible de manera segura (RNF-004).
