Sección 1 · Descripción general del proyecto

Del Excel crudo al dashboard

Qué problema resuelve el sistema y cuál es su objetivo.

Problema o necesidad identificada

Actualmente, la empresa NetPlus utiliza el sistema Z-BioTime para el registro biométrico de su personal. El problema radica en que la plataforma solo exporta los datos crudos en formato Excel, obligando al Asistente de Recursos Humanos a realizar diariamente una revisión manual exhaustiva para cruzar marcaciones, calcular atrasos y registrar justificaciones. Esta carga operativa es ineficiente, propensa a errores humanos y retrasa la consolidación mensual necesaria para el pago de la nómina.

Objetivo de la aplicación web

Desarrollar un sistema web interactivo (Dashboard DCAA Nettplus) que automatice la importación, validación y procesamiento de los reportes Excel de Z-BioTime (marcaciones, permisos, vacaciones, horas extras). El sistema cuenta con un motor de reglas que procesará la información para generar tres salidas clave: un dashboard diario de asistencia, un consolidado mensual de nómina y un panel de indicadores estratégicos.

Sección 2 · Identificación de usuarios

3 roles

El sistema restringe las vistas y acciones según el rol del usuario autenticado.

Rol Qué hace
Recursos Humanos (RRHH) Es la única puerta de entrada de datos al sistema. Responsable de cargar los archivos Excel, validar la estructura y visualizar el dashboard diario (totales de ausentes, atrasados, horas extras y vacaciones).
Contabilidad Responsable de generar y revisar el resumen de nómina mensual por colaborador (utilizando el corte del 21 al 20). Tiene permisos para exportar este consolidado en formatos estandarizados (Excel y PDF). No carga archivos.
Desarrollo Organizacional (DO) Rol estratégico con acceso de solo lectura a los datos diarios. Visualiza los indicadores (asistencia, headcount y rotación), registra las altas/bajas de personal y administra el sistema (gestión de usuarios y configuración de parámetros como tolerancias y cortes). No carga archivos.

Inicio por rol: RRHH → Dashboard diario · Contabilidad → Resumen de nómina · DO → Indicadores

Sección 3 · Alcance del proyecto (MVP)

Qué entra y qué no

Funcionalidades de esta primera versión y lo que queda fuera.

Incluido en el MVP

  • Autenticación segura mediante JWT y contraseñas cifradas (Argon2).
  • Importación, validación de estructura y limpieza de reportes Excel de Z-BioTime.
  • Motor de reglas en el servidor: cálculo de atrasos (con tolerancia configurable), horas extras (suplementarias y extraordinarias) y turnos.
  • Gestión de cortes mensuales dinámicos (por defecto, del 21 del mes anterior al 20 del mes actual).
  • Dashboards separados por rol: Diario (RRHH), Nómina (Contabilidad) e Indicadores (DO).
  • Soporte para recarga de archivos sin duplicación de registros (carga transaccional).

Fuera del alcance de esta versión

  • Conexión directa mediante API o base de datos nativa con el hardware del reloj biométrico Z-BioTime.
  • Envío de alertas automáticas por correo electrónico (clasificado como mejora futura).
  • Descuento o control de la hora de almuerzo.
